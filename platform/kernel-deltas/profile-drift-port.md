1. 单一上游的取数与仓名常量。本仓靠前缀路由选仓，这是本仓存在的理由，不能换。
2. 符号锚与区间行号进门禁。上游那套为它自己的 profile 写法服务。本仓现在的锚点写法
   （见 profile 文件头「写锚点的四条规矩」）在 102 条上核出来是 0 漂移、0 核不了。

4. 上游自测里针对 N.E.K.O 路径的用例。搬过来只会测一个本仓不用的分支。

下次 bump 的做法：先看 `git diff <上次ack的sha>..-- scripts/profile_drift.py` 的上游侧改动，
按上面这个格式逐条判「并 / 不并 + 理由」，然后才跑 `--port-done`。别攒着。
